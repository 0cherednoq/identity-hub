# Руководство Identity Hub

Руководство отвечает на вопрос «как этим пользоваться»: как добавить аккаунт, перевести его
в работу, выдать воркеру, ограничить нагрузку, забанить, верифицировать и синхронизировать
статусы с платформой. Установка и быстрый старт — в [корневом README](../../README.md),
эксплуатация — в [CLI](../cli.md) и [интеграции](../integrations.md).

Весь API асинхронный. Примеры проверены на `MemoryStore`; с PostgreSQL код тот же, меняется
только конструктор `IdentityHub` (см. [быстрый старт](../../README.md#быстрый-старт)).

Начните с [карты API](api.md): точка входа, какие сущности где лежат и типовые операции по
каждой из них.
