# Публичный `Observation` расходится с внутренним

**Библиотека:** `identity_hub==1.0.0a2`. Пути — от `site-packages/identity_hub/`. Найдено чтением кода и тестами server-admins (хаб на `MemoryStore` и на PostgreSQL).

**Тип:** документация. **Важность:** низкая.

Публичный `Observation` (`state.py`, стр. 62–77) требует `region` и `key`, внутренний
`domain/regions.Observation` — нет; `observed_at` по умолчанию — время хранилища. Пример в
документации построен на внутреннем варианте, и код по нему не собирается.

**Предложение:** выровнять пример в документации с публичным типом.
