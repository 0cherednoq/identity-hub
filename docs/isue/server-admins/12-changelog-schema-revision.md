# Changelog указывает неверную head-ревизию схемы

## Претензия

Раздел релиза `1.0.0a3` сообщает, что head-ревизия схемы равна `0035`.

## Подтверждение

Претензия обоснована. Код задаёт `SCHEMA_HEAD = "0036"`, а миграция
`0036_service_url.py` входит в тот же релиз. Упоминание `0035` в описании точечной валидности
credentials корректно, но итоговая ревизия релиза в вводном абзаце changelog должна быть `0036`.
