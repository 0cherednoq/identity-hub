# Скрипты воспроизведения находок ревью

Разовые скрипты, которыми подтверждались находки из
[`PRE-RELEASE-REVIEW.md`](../PRE-RELEASE-REVIEW.md). Это не тесты: pytest их не собирает, ruff
и mypy их не проверяют.

После очереди исправлений `F` (задача `F7.1`) остались только скрипты находок, перенесённых в
очередь улучшений; остальные удалены, потому что их находки покрыты тестами в `tests/` (раздел
«Статус исправлений» ревью). Удалённые скрипты есть в истории git до коммита `fix(F7.1)`.

| Скрипт | Находка | Задача | Что нужно для запуска |
|---|---|---|---|
| `schema/sch_e9_explain.py`, `schema/sch_e6_runtime.py` | `R2-D08` (N+1 в поиске админки), `R2-D09` (список без индекса) | `I6.2` | PostgreSQL 16, адрес и порт в `schema/sch_common.py` |

Скрипты писались под API `1.0.0a1` и временные контейнеры: перед запуском подставьте свой адрес
БД и переведите вызовы на текущий API (`hub.space(..., create=True)`, обязательный `actor`,
неймспейсы вместо плоских методов). Когда задача улучшений закроет находку тестом, скрипт удаляется.
