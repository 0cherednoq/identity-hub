# Handoff resource management для Tallyho

Этот файл перечисляет точечные изменения внешней спецификации
`talyho/docs/resource-management.md`. Он не изменяет репозиторий Tallyho и служит входом для
отдельной очереди интеграции.

## Расширить классификацию отказов аренды

Таблица обработки `LeaseUnavailable` должна покрывать все пять значений
`LeaseUnavailableReason`:

| Причина | Действие consumer | Сигнал восстановления |
|---|---|---|
| `busy` | defer с ограниченным backoff или `retry_after` | аренда освобождена или истекла |
| `no_candidates` | `defer(reason="no_resources")`, окно 0 | identity создана, активирована или снова прошла фильтр |
| `no_proxy` | `defer(reason="no_proxy")`, не заказывать identity | прокси добавлен, освобождён или снова alive |
| `quota` | defer на `retry_after` секунд | открылось ближайшее окно квоты |
| `reserve` | `defer(reason="reserve")`, проверить расчёт по `allocatable` | ёмкость выросла или изменён резерв приоритетного вызова |

`LeaseUnavailable.retry_after` является относительной задержкой в секундах.
`QuotaExhausted.retry_at` является абсолютным временем открытия окна конкретной квоты. Эти поля
нельзя передавать в один и тот же API очереди без преобразования.

## Удалить устаревший typing-workaround

Поле `IdentityCreate.service` принимает `str | Service`. Если объект сервиса уже импортирован,
используйте его напрямую:

```python
created = IdentityCreate(
    service=SERVICE,
    external_ref=external_ref,
)
```

Утверждение, что конкретный `Service[Credentials, Session]` не принимается из-за инвариантности,
устарело. Не требуется заменять все строки на объекты: `service="telegram"` остаётся корректным,
когда имя поступает из конфигурации, API или сохранённых данных.

## Пробуждать governor по восстановлению ёмкости

Адаптер Identity Hub должен подписаться на `pool.capacity.ok` и вызывать `governor.kick()`.
Payload содержит `pool`, `previous_state`, `eligible` и `free`; `service` и `space` находятся в
стандартных полях события.

Событие ускоряет реакцию, но не заменяет периодический tick. Пулы являются объектами кода и не
хранятся в глобальном реестре, поэтому создание identity, снятие бана, выход из
карантина/`COOLING` и открытие квотного окна не всегда можно сопоставить с конкретным пулом.
