## Открытые пункты

1. **Бюджеты аренды и `operation` под нагрузкой не подтверждены** (`D-127`, `PERF-1` остаются
   открытыми, `D-332`). На этом хосте девять тривиальных `SELECT` в одной транзакции дают p95
   8.8 мс при одном воркере и 2515.7 мс при 64: пустые транзакции без участия библиотеки уже
   превышают бюджет аренды в двадцать раз. Аренда библиотеки — около 20 % поверх этого пола.
   Что нужно: прогон на изолированном стенде (выделенные CPU, PostgreSQL без Docker Desktop,
   пул под уровень параллелизма). Критерий пригодности стенда — `tests/load/test_infra_baseline.py`:
   если пол окружения на нужном уровне параллелизма выше бюджета, остальные цифры не
   информативны. До такого прогона `xfail` у load-тестов не снимаются.
2. **Версия RC и публикация** — решение владельца (`D-333`). Пакет остаётся на `1.0.0a5`;
   `CHANGELOG` ведёт раздел `Unreleased`.
3. **`IMP-22 RuntimeProfile`** — вне очереди по `D-142`, нужен отдельный план.

## Как воспроизвести

```bash
uv sync --frozen --all-extras      # без extras нет asyncpg и pg-тесты падают на импорте
bash scripts/check.sh              # обычный gate: ruff, mypy, lint-imports, pytest -m "not load"
uv run pytest tests/pg/test_race_matrix.py -q            # матрица гонок
uv run pytest tests/load -m "" -q --timeout=480          # load: 7 passed, 7 xfailed
uv run pytest tests/load/test_infra_baseline.py -q -s -m ""   # пригодность стенда
```

Docker Desktop должен быть запущен: тесты с маркером `pg` поднимают PostgreSQL через
testcontainers, либо задайте `IH_TEST_DATABASE_URL`.
